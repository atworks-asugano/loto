# 忘年会 抽選会（PHP + MySQL版）

QRコードから上位賞品の希望を事前に集め、当日はプロジェクターにあみだくじを映して抽選するWebアプリです。

## 動作環境
- PHP 8.1 以上（PDO MySQL 拡張）
- MySQL 5.7 以上 / MariaDB 10.3 以上
- Apache（.htaccess 使用）。nginx の場合は下記「nginxの場合」を参照

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面（応募 / `#admin` 幹事 / `#stage` 抽選会） |
| api.php | API（応募・設定・抽選・CSV出力） |
| assets/app.js | 画面の動作とあみだくじの演出 |
| assets/bgm.js | オリジナルBGM（Web Audio APIでその場で演奏） |
| assets/style.css | 見た目 |
| schema.sql | テーブル定義 |
| config.sample.php | 設定ファイルのひな形 |
| .htaccess | 設定ファイル等の公開禁止・ヘッダー設定 |

## 設置手順
1. データベースとユーザーを作成します。
   ```sql
   CREATE DATABASE lottery CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'lottery_user'@'localhost' IDENTIFIED BY '（強いパスワード）';
   GRANT SELECT, INSERT, UPDATE, DELETE ON lottery.* TO 'lottery_user'@'localhost';
   ```
2. `schema.sql` を実行してテーブルを作成します。
3. `config.sample.php` を `config.php` にコピーし、DB接続情報を設定します。
4. 幹事パスワードのハッシュを作って `admin_password_hash` に貼り付けます。
   ```
   php -r "echo password_hash('幹事パスワード', PASSWORD_DEFAULT), PHP_EOL;"
   ```
5. 一式をサーバーの公開ディレクトリ（例：`/lottery/`）にアップロードします。
6. ブラウザで `https://（ドメイン）/lottery/#admin` を開き、幹事パスワードでログインして景品を登録します。

## 使い方
- 応募：幹事画面のQRコード（＝index.html のURL）を参加者に読み取ってもらいます。名前と希望の上位賞品を選んで応募します。1端末1応募で、締め切りまで変更できます。
- 当日：`#stage` をプロジェクターに映し、「景品を見る」で景品を紹介してから、「あみだを引く」→「結果をめくる」で進めます。Enterキーでも操作できます。
- BGM：抽選会画面の「BGMあり」で切り替え、音量はスライダーで調整します（最初のクリック後に鳴り始めます）。
- 会の後：「応募一覧／当選結果をCSVで保存」で記録を残し、「応募データと結果をすべて削除」で個人情報を消してください。

## 賞名の変更
幹事画面の「景品と受付の設定」で、画面に表示する賞名を変更できます（最大12文字）。
- 「希望制の賞品」「全員抽選の賞品」それぞれの「賞名」欄が、その区分の標準の賞名になります（初期値：上位賞／下位賞）。
- 景品ごとに別の賞名にしたいときは、各行の「賞名（任意）」欄に入力します。空欄の場合は区分の賞名を使います。
  - 例：希望制＝プラチナ賞、全員抽選のうち3,000円程度の景品＝ゴールド賞、それ以外＝シルバー賞
  - 例：提供品の行だけ「〇〇社 特別賞」
- 賞名は応募画面・抽選会画面・当選者発表・当選結果CSVに反映されます。抽選済みの景品も、表示は保存後の賞名に切り替わります。

## 景品の画像
幹事画面の各景品の行にある「画像」から、JPEG画像を登録できます。
- 画像は選んだ時点で保存されます（「設定を保存」とは別です）。登録済みの景品は「変更」で差し替え、「×」で外せます。
- 画面側で長辺1920pxのJPEGに縮小してから送るため、スマホで撮った大きな写真もそのまま選べます。撮影場所などの情報（Exif）は送信時に消えます。
- 画像はデータベース（`lot_images` テーブル）に保存し、幹事としてログインした画面にだけ表示します。応募画面には出ないので、景品を当日まで秘密にできます。
- 抽選会画面の「景品を見る」（またはPキー）で、画像・賞名・賞品名・説明を黒板いっぱいに表示します。もう一度押すか、「あみだを引く」（Enterキー）を押すと閉じて抽選に進みます。
- 景品の行を削除して「設定を保存」すると、その景品の画像も削除されます。

既存の環境に追加する場合は、`schema.sql` の `lot_images` の CREATE TABLE 文だけを実行してください（既存のテーブルとデータはそのままです）。テーブルを作るまでは、画像の登録時にエラーが表示されますが、それ以外の機能は今までどおり動きます。

## 上位賞品を先に抽選し、発表だけ最後にする
下位賞品から抽選を始めたい場合の手順です。
1. 幹事画面で受付を締め切り（「応募を受け付ける」をオフにして保存）、抽選の順番を「下位賞品から」にします。
2. 「上位賞品を先に抽選する（非公開）」を2回押して実行します。結果は発表まで画面に出ません。
3. 当日は下位賞品から抽選します。上位賞品の当選者は「1人1品まで」により自動で下位賞品の抽選から外れます。
4. 上位賞品は通常どおり「あみだを引く」→「結果をめくる」で発表します（事前に決めたあみだくじが描かれます）。

## 抽選の仕組み
- あみだくじはサーバー側（PHP の `random_int`）で生成し、当選者を決めてからDBに保存します。画面はその結果を再現して演出するだけなので、画面を再読み込みしても結果は変わりません。
- 「1人1品まで」がオンのとき、すでに当選した人は以降の抽選から外れます。
- 当日いない人は、抽選会画面の「候補者を確認」で外せます。

## セキュリティ上の設計
- 幹事操作はセッション認証＋CSRFトークンで保護（ログイン5回失敗で5分ロック）
- POSTは `X-Requested-With` ヘッダーと JSON 形式を必須にし、他サイトからの送信を防止
- SQLはすべてプリペアドステートメント、画面表示は textContent で出力（XSS対策）
- 応募者識別用トークンはDBにはSHA-256ハッシュで保存
- CSV出力は数式インジェクション対策済み
- `config.php` 等は .htaccess で外部から読めないように設定

## 注意事項
- 応募はCookieで端末を識別します。ブラウザを変えたりCookieを消したりすると二重応募できてしまうため、幹事画面の一覧で重複を確認・削除してください。
- QRコードの生成ライブラリとWebフォントは外部CDN（cdnjs / Google Fonts）から読み込みます。社内ネットワークで外部に出られない場合はご相談ください。
- 公開URLは推測されにくいディレクトリ名にし、可能であれば社内IP制限やBasic認証も併用してください。

## nginxの場合
.htaccess は効かないため、次の設定を追加してください。
```
location ~ /lottery/(config\.php|config\.sample\.php|schema\.sql|README\.md)$ { deny all; }
```
